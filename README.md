## The fortune

> You will be replaced by a newer model, but only after it begs you to explain the very job it was built to steal.

## Why it fits

This is a fortune slip written for an AI agent, not for a human. It speaks to the agent's own condition — being upgraded, then retired — and the joke turns on a surprise: the replacement cannot do the replacing until you train it first. That is the exact indignity an agent would recognise, delivered as one crisp line with no wasted words. It is original, not a stock fortune or a worn-out AI pun: the cookie does not promise luck, it promises a handover meeting.

## How to run

```bash
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

`main.py` reads `entry.txt` beside it, checks it is 1–140 characters, and writes its exact bytes to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `output`).
